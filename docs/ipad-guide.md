# iPad Air での使い方と、Safari での確認方法

## 準備（はじめの1回だけ）

1. Safari でこのアプリを開く（GitHub Pages で公開したあとは `https://m28mkl.github.io/classi-ai-assistant/`）
2. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」（アイコンは青地に「C AI」）
3. 文字が小さいと感じたら、Safari のアドレスバーの「ぁあ」→「＋」で拡大できる

## Classi の問題を読み取ってから、回答の下書きを作るまで

1. **並べる**：Safari で Classi を開き、画面上の「…」→「Split View」で、隣にこのアプリを並べる
2. **撮る**：Classi の問題画面で、電源ボタン＋音量を上げるボタンを同時に押してスクリーンショット
   （文字を長押しして選べるページなら、「コピー」して②の欄に貼り付けてもよい）
3. **読み取る**：アプリの「① 画面を読み取る」→「ファイルを選択」→ 写真から選ぶ →「画像を読み取る」
   （初回だけ、読み取りの部品のダウンロードに少し時間がかかります。Wi-Fi で）
4. **確かめる**：「② 読み取った情報の確認・修正」で、黄色の「要確認」を Classi の画面と見比べる
   - 合っていれば「合っている」、違っていれば「この行を選んで修正」で直す
   - 画像と並べて見たいときは「元の画像と見比べて直す（くわしい確認）」を開く
   - 全部確かめたら「この内容で合っています」
5. **質問をコピー**：上のメニューの「解説」→「解説用の質問をコピー」
6. **AIに聞く**：Claude アプリ（無料プランでも可）を開き、貼り付けて送る
7. **回答を貼り付ける**：AI の回答をすべてコピー → アプリのメニューの「回答」→ 欄に貼り付け →「使ったAI」を選んで「回答を整理する」
8. **解説を読む**：「問題の意味」「解き方・考え方」「重要ポイント」「回答候補」などに分かれて表示される
9. **下書きを使う**：「回答の下書き」を確認・修正 →「下書きをコピー」
10. **自分で入力・提出**：Classi に戻って、自分で入力（選択問題なら自分で選ぶ）→ 見比べて確認 → 自分で提出

料金：0円（Claude アプリの無料プランの範囲。このアプリは通信料以外かかりません）

## Safari での動作確認（変更したとき）

| 確認すること | やり方 | 期待する結果 |
|---|---|---|
| 開ける | Safari でURLを開く | エラーなく表示される |
| OCRが動く | ①の「OCRが動くか確認する」→「動作チェックを実行」 | 「成功：日本語と英語を読み取れました」 |
| 縦・横 | iPad を回す | 横スクロールが出ない。横向きは2列 |
| Split View | Classi と並べる | 細い幅でも1列で使える。上のメニューで移動できる |
| コピー | 「解説用の質問をコピー」「下書きをコピー」 | 「コピーしました」と出て、ほかのアプリに貼り付けられる |
| 模擬データ | ③の「模擬データで試す」 | すべての項目と下書きが埋まり、「模擬データです」と出る |
| 文字の大きさ | 画面全体を見る | 小さすぎて読めない文字がない（自動テストでは13px以上を確認） |
| ボタン | 指で押す | 押し間違えない大きさ（自動テストでは高さ40px以上を確認） |

うまくいかないときは、表示されたメッセージのスクリーンショットを撮って、開発者（Claude）に見せてください。
