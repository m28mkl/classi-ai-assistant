# iPad 実機テストのチェックリスト

iPad Air の Safari で、Classi の問題を読み取ってから回答の下書きを作るまでを、実際に試すための手順です。
結果は下の表に ○ / × で記録し、× のときは画面のスクリーンショットを開発者（Claude）に見せてください。

## はじめに（1回だけ）

- アプリのURL：`https://m28mkl.github.io/classi-ai-assistant/`（試験公開の設定をしたあと）
- 練習用の画像：`https://m28mkl.github.io/classi-ai-assistant/tests/fixtures/classi-like-q01.png`
  （架空の問題画面です。実際の Classi で試す前に、これで練習できます。開いて長押し →「"写真"に保存」）
- 初回の読み取りでは、読み取りの部品（約9MB）をダウンロードするので Wi-Fi で行ってください

## 手順と確認すること

| # | やること | 確認すること | 結果 |
|---|---|---|---|
| 1 | Safari で Classi の問題画面を開き、「…」→「Split View」で隣にこのアプリを開く | 2つが並んで表示される。アプリに横スクロールが出ない | |
| 2 | Classi の画面で、電源ボタン＋音量を上げるボタンを同時に押す | 左下に小さな画像が出て、「写真」に保存される | |
| 3 | アプリの「① 画面を読み取る」→「ファイルを選択」→「写真ライブラリ」→ 撮った画像 →「画像を読み取る」 | 進み具合（%）が出て、「読み取り完了！」になる（初回は1分ほどかかることがある） | |
| 4 | 「② 読み取った情報の確認・修正」を見る | 問題文・選択肢が読み取れている。自信がない所は黄色の「要確認」と切り抜き画像で出る。直したら「この内容で合っています」 | |
| 5 | 上のメニューの「解説」→「解説用の質問をコピー」 | 「コピーしました！」と出る | |
| 6 | Claude アプリを開き、入力欄を長押し →「ペースト」→ 送る | Claude が【問題の意味】【解き方・考え方】…の見出しつきで答える | |
| 7 | Claude の回答の下の「コピー」ボタン → アプリに戻り、メニューの「回答」→ 欄を長押し →「ペースト」→「回答を整理する」 | 「回答を整理しました」と出て、解説の各項目が埋まる | |
| 8 | 「回答の下書き」を読み、必要なら直して「下書きをコピー」 | 「下書きをコピーしました」と出る。Classi には自分で入力・提出する | |

## うまくいかないとき

| 症状 | 考えられる原因と対処 |
|---|---|
| 「読み取りエラー：OCRライブラリを読み込めませんでした」 | インターネットにつながっていない、またはコンテンツブロッカーが cdn.jsdelivr.net を止めている。Wi-Fi を確認し、ブロッカーで許可する |
| 読み取りにとても時間がかかる | 初回はダウンロードがあるため。2回目からは速くなる。画像が大きすぎる場合は自動で縮小される |
| 読み取った文字が違う | 「要確認」を見比べて直す。「① 画面を読み取る」の「画像を補正して読み取る」をオンにして読み直すと良くなることがある |
| 「コピーしました」が出ない | 「文章を選択しました」と出たら、表示された文章を長押しして「コピー」する |
| 回答が項目に分かれない | Claude に質問文を「そのまま」貼り付けたか確認する（見出しの指定が質問文に入っています）。分かれなくても、全文は「解き方・考え方」に入る |
| Split View にできない | iPad の設定 →「マルチタスクとジェスチャ」で Split View が使えるか確認する |

## 注意

- 学校や先生がAIの利用を認めていない課題やテストには使わないでください
- 答えは必ず自分で確かめ、Classi への入力と提出は自分で行ってください
- 撮ったスクリーンショットは、このアプリから外に送信されません（Claude アプリに送るのは、自分でコピーした質問文だけです）
