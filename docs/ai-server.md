# AI解説サーバー（OpenAI gpt-6-luna）

画面の「AIに解説してもらう」は、この `server/` を通って OpenAI の **Responses API** を呼びます。
**APIキーはサーバーの環境変数にだけ置き、画面（GitHub Pages）には書きません。**

```
[iPad Safari：このアプリ] ──(確認画面で「送る」)──▶ [AI解説サーバー server/] ──▶ [OpenAI Responses API]
        OCRはここ（ブラウザ内）                    APIキー・料金表・予算の記録はここだけ
```

## 守っていること

| 条件 | どう守っているか |
|---|---|
| APIキーは環境変数 | `OPENAI_API_KEY` だけ。画面・Git・応答・ログに出さない（テストで確認） |
| OCRはブラウザ内 | 変更なし。画像はどこにも送らない |
| 確認した問題文だけ送る | 「② この内容で合っています」を押すまで、AIボタンは使えない。送る内容は確認画面に**そのまま**表示し、「送る」を押したときだけ通信する |
| 1回の入力は4,000トークンまで | 送る前に OpenAI の公式の数え方（`/v1/responses/input_tokens`）で数え、超えたら送らない。数えられないときは、安全側（バイト数）で判断する |
| 1回の出力は800トークンまで | `max_output_tokens: 800`。考えるためのトークンも含まれるので、`reasoning.effort` は `low`（`OPENAI_REASONING_EFFORT` で変更可） |
| 1日50回まで | 日本時間で日付が変わると戻る。通信を始めた回数で数える（失敗しても戻さない） |
| 推定300円でアプリ側のAI利用を停止 | 下の「予算の仕組み」 |
| 利用額と回数を表示 | 画面の「今日の利用回数」「今月の推定利用額」 |
| APIエラーで安全に停止 | 下の「エラーのとき」 |
| AI未接続でも既存機能が使える | 接続先が空・つながらない・停止中でも、OCR・整理・質問文のコピーは今までどおり |

## 重要：300円は「推定」で、請求の上限ではありません

- 推定利用額は、**サーバーが受け取ったトークン使用量（usage）× `pricing.json` の料金表 × 為替**で計算した値です。
- アプリ側でAIを止めるための目安です。**OpenAIの請求を止める仕組みではありません。**
  サーバーが止まっている・台帳を消した・別の場所から同じAPIキーを使った場合などは、止まりません。
- 月額500円以内に収めたいときは、**OpenAI側の支出の上限や通知の設定も別に**確認してください。
- OpenAIの報告する出力トークン数が実際より多くなる不具合の報告（コミュニティ）があります。このアプリは**報告された数をそのまま**使うので、推定額は多めに出ることがあります（安全側）。

## 予算の仕組み

1. 送る前に**最悪額**（入力トークン数 × 入力単価 ＋ 出力800トークン × 出力単価）を計算
2. 「今月の確定額 ＋ 処理中の予約 ＋ 最悪額」が300円を超えるなら、送らずに停止
3. 通れば最悪額を**予約**して送信（同時に何件来ても、予約は1つずつ順番に処理）
4. 応答の**実際の使用量**で料金を計算して確定（予約は解除）
5. 使用量が読めない・モデル名が違うときは、**最悪額で確定**（少なく見積もらない）

台帳は `server/data/ledger.json`（回数・金額・停止の状態だけ。問題文は保存しません）。
台帳が壊れているときは、ゼロに戻さず**AIを止めます**。月の切り替わりは日本時間です。

## 料金表（コードに固定しません）

`server/pricing.json` に、モデルごとの単価（100万トークンあたりの米ドル）と為替を書きます。

```json
{
  "updated_at": "2026-11-16",
  "usd_jpy": 160,
  "models": { "gpt-6-luna": { "input_per_1m_usd": 0.10, "cached_input_per_1m_usd": 0.01, "output_per_1m_usd": 0.50 } }
}
```

- 値は 2026-11-16 に [OpenAIの gpt-6-luna のページ](https://developers.openai.com/docs/models/gpt-6-luna)で確認したものです。**料金は変わることがあるので、定期的に見直してください。**
- `usd_jpy` は初期値160円です。実際のレートより高めにすると、推定額が多めになり安全です。
- 更新日から60日（`stale_after_days`）たつと、画面に警告が出ます。
- 別のファイルを使うときは `PRICING_FILE`、別のモデルを使うときは `OPENAI_MODEL`（料金表にないモデルは起動しません）。

## エラーのとき

| 状況 | 動き |
|---|---|
| OpenAIが4xxで拒否（キー違い・不正な要求など） | 請求されていないので予約を戻す。安全なメッセージだけ画面に出す（OpenAIの文面は出さない） |
| 通信エラー・時間切れ（既定30秒）・5xx・読めない応答 | 請求の可能性があるので**最悪額で記録** |
| キー違い（401/403）・残高不足 | 1時間AIを停止 |
| 連続3回の失敗 | 10分AIを停止（時間がたてば自動で再開） |
| 回答が長さの上限で途切れた／AIが断った／形式が違う | 回答は表示しない。使った分は記録 |
| 再試行 | **しません**（記録されない料金が増えるため） |

## 動かし方

Node.js 22 が動く場所で、**環境変数**を設定して起動します（追加のインストールは不要）。

```bash
OPENAI_API_KEY=（あなたのキー） ACCESS_CODE=（長い合言葉） npm run server
```

| 環境変数 | 意味 |
|---|---|
| `OPENAI_API_KEY`（必須） | OpenAIのAPIキー |
| `ACCESS_CODE`（必須） | 画面で入力する「利用コード」。知らない人にAPIを使われないための合言葉（試験だけなら `ALLOW_NO_ACCESS_CODE=1`） |
| `ALLOWED_ORIGIN` | 画面を置いたサイトのURL（例 `https://m28mkl.github.io`）。GitHub Pagesから使うときに必要 |
| `SERVE_STATIC=1` | サーバーから画面も配る（接続先は自動で `/api`）。この場合 `ALLOWED_ORIGIN` は不要 |
| `HOST` / `PORT` | 待ち受け（既定 `127.0.0.1:8787`） |
| `DATA_DIR` | 台帳の保存先（**消えないディスク**を指定） |
| `MAX_INPUT_TOKENS` `MAX_OUTPUT_TOKENS` `DAILY_MAX_CALLS` `MONTHLY_STOP_JPY` | 既定は 4000・800・50・300 |

見本は `.env.example` です（本物のキーを入れたファイルはGitに入れないでください）。

### 画面とサーバーをつなぐ

- **サーバーから画面も配る**（`SERVE_STATIC=1`）：`https://（サーバー）/` を開くだけ。
- **GitHub Pagesの画面を使う**：`index.html` の `<meta name="classi-ai-endpoint" content="">` の `content` に、`https://（サーバー）/api` を入れます。
  接続先は「同じサイトのパス」か「https」だけ（手元の試験用に `http://127.0.0.1` も可）。空のままなら「AI未接続」で動きます。

### 注意

- **サーバーは1つだけ**動かしてください（台帳をファイルで持つため）。複数に増やす・サーバーレスにするときは、台帳の保存先を共有の保存場所に変える必要があります（未対応）。
- 台帳のファイルを消すと、回数と金額が0に戻ります。
- 公開するなら必ず https にしてください（利用コードが通信を流れます）。
- 入力トークンの数え方の呼び出し（`/v1/responses/input_tokens`）に料金や回数制限があるかは、公式ドキュメントに書かれていませんでした。OpenAIの料金・制限のページで確認してください。
