# Classi Web版との連携・操作補助の調査（2026-11-17）

追加費用0円（上限は月500円）で、Classiの利用規約やセキュリティに反しない方法だけを選ぶための調査です。

## 前提（守ること）

- ログイン情報（ID・パスワード）を、このアプリで入力・保存・送信しない
- ログイン、CAPTCHA、多要素認証、学校のアクセス制限を回避しない
- Classiのサーバーに、このアプリから直接アクセスしない（自動で読み込む・自動で操作する、をしない）
- 課題の回答の入力と提出は本人が行う（アプリは下書きまで）
- 学校や先生がAIの利用を認めていない課題には使わない

Classiの利用規約の全文は、Classiの中（アカウント → 利用規約）で確認できます。この調査では全文を読めなかったため、**「Classiのページに手を加える」方法は、本人が規約と学校のルールを確認するまで採用しない**ことにしました。なお、学校向けの資料では、Classiの動作保証環境として iPadOS 14.0以上 ＋ Safari が挙げられています。

## 結論

今いちばん安全で、費用も0円なのは、次の流れです（すべて実装ずみ）。

1. Classi の問題画面をスクリーンショット（または文字をコピー）
2. このアプリで読み取り → 要確認を直す → 「この内容で合っています」
3. 質問文をコピー → Claudeアプリなどで聞く → 回答を貼り付けて整理
4. 下書きを直してコピー → Classi に自分で貼り付け → 見比べて確認 → 自分で提出

この流れなら、Classiのページにもサーバーにも手を加えません。
