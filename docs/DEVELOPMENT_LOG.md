# 開発記録（Classi AI Assistant）

完成した機能と、残っている課題を記録します。新しい順に書きます。

## 方針（2026-11-17 時点）

- 追加予算は月500円以内。無料でできる方法を最優先にする
- OpenAI などの有料APIは、まだ接続しない（`server/` のコードはあるが使っていない）
- Classiへの自動提出・自動入力はしない。下書きまでを作り、入力と提出は本人が行う
- ログイン・CAPTCHA・多要素認証などの本人確認を回避しない
- main は直接変更しない。作業ブランチで開発し、マージ前に報告する

## 2026-11-17：要確認の整理・Classi連携の調査・iPad対応・公開の準備（ブランチ `claude/ai-paste-answer`）

完成した機能
- 「要確認」を②の1か所にまとめた（自信がない単語の切り抜き画像・確信度、推測で直したところも一緒に表示）
- 右側の「読み取り結果の確認」を、②の中の「元の画像と見比べて直す（くわしい確認）」に移動
- 不具合修正：くわしい確認で「反映」しても、確認済みが取り消されなかった
- iPad：ホーム画面のアイコン、移動メニューに「回答」を追加、小さすぎる文字（12px）を13pxに
- 調査：[Classi Web版との連携](classi-integration.md)、公開の準備：[GitHub Pages](github-pages.md)、[iPadでの使い方](ipad-guide.md)

## 2026-11-17：AIの回答の貼り付け・回答の下書き（ブランチ `claude/ai-paste-answer`）

完成した機能
- 質問文に「回答の形式（見出し）」を入れ、貼り付けた回答を項目に分けやすくした
- AIの回答の貼り付け欄と「回答を整理する」ボタン（使ったAIを選べる：Claude・ChatGPT・Gemini・その他）
- 回答を「問題の意味・解き方・重要ポイント・回答候補・回答の理由・間違えやすいポイント・下書き」に分ける（【】・Markdown・太字・番号つきなど、いろいろな書き方に対応）
- 回答の下書き（直せる・コピーできる・作り直せる）
- 模擬データ（通信なし、「模擬データ」と明記）
- AIを切り替えられる構造（`ai-assist.js` の `registerProvider`）

テスト：構文・単体・AIサーバー・Split View・iPad画面テストを手元で実行して合格。OCR本体を使うテストは GitHub Actions で確認。
